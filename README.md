# Texivi

Independent systems programmer. I write operating systems, window managers and Mac apps in C, Rust, x86-64 assembly and Swift.

## Projects

- [Subverge](https://github.com/texivi/Subverge): a hobby x86-64 operating system written from scratch, with a stack-language shell. [Site](https://sbvrg.github.io)
- [UraniumOS](https://github.com/uranium-os): a Linux distribution with btrfs snapshots and its own package manager, rod. [Site](https://uranium-os.github.io)
- [Fluent](https://github.com/fluent-mac/fluent): a Mac app for typing practice, gesture lessons and checking a used Mac. [Site](https://fluent-mac.github.io)
- [TSWM](https://github.com/texivi/tswm): an X11 window manager that copies Syllable Desktop.
- [AVTTY](https://github.com/texivi/avtty): a very small text editor for the terminal.
